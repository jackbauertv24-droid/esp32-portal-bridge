Log in through the board (assisted)

Opens the upstream login page through the board. Fill it in as usual, but you can type <phone> in the number box and <code> in the code box: the board puts in the SIM's number and the code from the SMS it receives. Everything is recorded. Because the board sends every request, the login unlocks the board for all devices.

Leave empty to use the page found by the internet check.

About

    
Names come from the device itself when it joins (most phones send one); rename any device here. Phones often use a private address that changes per network or over time, so the same phone can show up again as a new device.

    
Block stops a device's internet but keeps it connected (it can still open this admin page, which is password protected). Disconnect drops it once; it may join again by itself. Data counts are since the device was first seen and are saved every 10 minutes.

    
Turn on Settings › Hotspot › Alert when a new device joins to be told through Telegram, webhook or MQTT.

About

    
Turn recording on and set the interval under Settings › Tracker. The GNSS antenna must be connected and see the sky; the first fix can take a few minutes. Without a fix, points still record the 4G signal, so you can map coverage by time.

    
Location by SMS: set a keyword and the numbers allowed to ask under Settings › Tracker. Texting the keyword from an allowed number gets a reply with a map link. Positions stay on the board; they are never put into reports.
